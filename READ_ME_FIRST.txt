GENEVIEVE SUPER RESPONSE — WINDOWS EDITION

STARTING THE APP
1. Extract the whole ZIP file first.
2. Open the extracted folder.
3. Double-click START_GENEVIEVE.bat.
4. Windows will check Python, create a private environment, install the required components and open the app.
5. In the app, select API key setup and add at least one provider key.

NEXT TIME
Double-click OPEN_APP.bat. If the local environment was removed, it automatically returns to the setup process.

REPAIR
Double-click REPAIR_APP.bat. It removes only the app's private Python environment and rebuilds it. It does not remove your API keys.

IMPORTANT
- Do not run app.py by double-clicking it.
- Do not move individual files out of this folder.
- Do not send confidential health, client, legal or business information to several external providers without appropriate consent and data controls.
- Each selected provider can charge separately.
- Agreement between several AI systems does not prove the answer is correct.
- Never share or upload your .env file.
